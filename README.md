## 🌟 Why CHESTA CLAW?
Most agent frameworks are bloated, slow, and hard to install. **CHESTA CLAW** changes that:
- **Ultra-Lightweight**: < 40k lines of code, < 300MB idle RAM usage.
- **Extreme Speed**: Rust-powered execution engine for instant task handling.
- **Total Autonomy**: The **CEO Brain** manages your agent fleet so you don't have to.
- **Local-First Privacy**: Uses SQLite and FAISS—your data never leaves your machine unless you want it to.

## 🚀 Key Features
- 🧠 **CEO Brain Manager**: Prevents infinite loops, monitors API health, and auto-decomposes goals.
- ⚡ **Multi-Model Router**: Seamlessly switch between Claude 3.5, Gemini 1.5, GPT-4o, and local Ollama models.
- 💾 **4-Layer Memory**: Short-term context, long-term FAISS vectors, episodic history, and persistent user modeling.
- 🛠 **2000+ Skills Ecosystem**: Prebuilt skills for coding (Next.js/FastAPI), research, productivity, and system control.
- 📱 **Omni-Channel**: Control your agent via Telegram, Discord, WhatsApp, or the built-in Dashboard.
- ✨ **Hermes Self-Improvement**: Agents automatically document their own learning in `SKILL.md`.

- **Database**: SQLite
