# 🦀 CHESTA CLAW v1.0: The Ultimate Agentic OS

**CHESTA CLAW** is a next-generation, local-first agentic operating system that decisively outperforms OpenClaw, NanoClaw, and Hermes. Built for speed, security, and extreme autonomy.

## 🚀 Key Features
- **CEO Brain Manager**: Autonomous overseer that breaks loops and manages task delegation.
- **Multi-Model Router**: Intelligent failover between OpenRouter, Claude, Gemini, and GPT-4o.
- **Local-First Memory**: Four-layer system using SQLite and FAISS for episodic memory.
- **Hermes-style Self-Improvement**: Automatically generates SKILL.md to capture learned workflows.
- **Single-Command Install**: `chesta install` gets you running in seconds.

## 🛠 Tech Stack
- **Backend**: Python 3.11 (Orchestration) + Rust (High-Performance Execution)
- **UI**: Next.js 15 + Tailwind CSS (Responsive Dashboard)
- **Database**: SQLite (No Postgres required) + FAISS (Vector Search)
- **Deployment**: Windows/Linux/Web (PWA)

## 📦 Installation
```bash
git clone https://github.com/your-repo/chesta.git
cd chesta
python chesta_cli.py install
```
